# 🌐 موقع nero — لوحة تحكم البوت

واجهة ويب كاملة لبوت nero، بتصميم زجاجي عصري ودعم كامل للعربية (RTL)، تعمل مباشرة على نفس قاعدة بيانات `telz_bot.db` حتى يشتغل البوت والموقع معاً.

---

## ✨ المميزات

### 🎨 واجهة المستخدم
- تصميم **زجاجي (Glassmorphism)** مع تأثيرات نيون
- **5 ثيمات**: Dark, Light, Cyberpunk, Ocean, Forest
- **3 لغات**: العربية (AR)، English (EN)، کوردی (KU) مع RTL/LTR تلقائي
- **Skeleton Loading** لكل قسم
- **Toast** أنيق + **Modal تأكيد** للعمليات الحساسة
- **Bottom Nav** على الجوال

### ⚙️ الوظائف
- تسجيل دخول بالمعرّف + نظام إحالات كامل
- خدمات: **اتصال، سبام آسيا، سبام اثير، سبام تيليجرام، سبام جيميل**
- **تكرار الاتصال (1-5) لـ VIP فقط** 👑
- **رفع ملف إيميلات جماعي** (txt/csv) للسبام جيميل
- **QR Code** لرابط الإحالة
- **سجل عمليات** موحّد (مكالمات + سبام + تحويلات)
- **إشعارات داخل الموقع** + **إشعارات Push** على المتصفح
- **شات دعم فني** مباشر مع الأدمن
- **بحث شامل** في السجل + المستخدمين (للأدمن)
- **مفضلة الخدمات** (حتى 5 خدمات تطلع أولاً)
- نقاط: تجميع، تحويل، استبدال
- اشتراك VIP
- **لوحة أدمن**: نقاط، VIP، إذاعة، صندوق دعم
- **لوحة مالك**: تشغيل/إيقاف الخدمات، الحدود، الأدمنز، القنوات
